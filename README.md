# Barbershop Booking CLI

CLI-утиліта для роботи з онлайн-записом через Altegio API.

Дозволяє:
- отримати список майстрів
- отримати список послуг для майстра
- знайти вільні слоти для запису (дати + час)

---

## 🚀 Можливості

- 🔍 Список майстрів
- ✂️ Список послуг конкретного майстра
- 📅 Пошук вільних слотів на найближчі 7 днів
- 🧠 Простий CLI-інтерфейс (зручно для агентів типу Claude Code)
